# トレカ成約価格検索

ALTの商品ページに表示される「Recent transactions」を、カード名・型番・PSAグレード・レアリティ・取引元で検索します。初期条件は **PSA8 × AR** です。

## 更新の仕組み

1. ChatGPTの定期タスクが、登録商品のALT公開ページをブラウザで確認します。
2. 取得できた成約履歴を、このリポジトリの `alt-sales-search/dist/data.json` に保存します。
3. サイトは5分ごと・画面に戻ったとき・「最新データを表示」を押したときに、GitHubの最新JSONを読みます。

定期実行は毎日11時ごろ（日本時間）です。これはChatGPT側で管理するタスクで、リポジトリをコピーするだけでは定期実行も複製されません。初回データは2026年9月10日に公開画面で確認しました。

**「最新データを表示」は取得済みデータの再読込です。押すたびにALTを取り直すボタンではありません。** 臨時の再取得はChatGPTに依頼してください。定期タスクは `dist/sync-status.json` を更新し、サイトに取得中・成功・失敗を表示します。失敗した場合、前回の履歴と取得時刻を維持します。

GitHub Actionsによる直接取得は、この実行環境では履歴欄を読み込めず検証に失敗したため、運用から外しました。通常ブラウザで確認できた手順を使います。

## データの範囲

`scripts/targets.json` にある7種類・8鑑定条件を対象にしています。ALTの全商品、すべてのPSA8 ARを網羅していません。初期収録は27件の取引です。対象は登録ファイルで追加できます。

ALTは掲載元で、実際の取引元にはeBay・Fanatics Collect等があります。取引元を区別して表示し、その条件に合う履歴の中から直近価格を計算します。

- 出品中のLowest price、現在の入札額、PSA人口を成約価格に含めません。
- 価格はALT画面のUSD表示値です。送料・税、ベストオファー金額の内訳、同日取引の時刻は確認していません。
- 公開ページのRecent transactions欄に出る最大4件程度を収録します。「View all」やログインが必要な履歴は対象外です。
- PSAグレード切替後も元の商品画像・ヘッダーが残る場合があるため、価格は選択したグレードの履歴から読みます。画像が別グレードのままの場合は画像を表示しません。
- 成約履歴がない商品は0円にせず、検索結果から除外します。

## 機能

- 日本語／英語名、ひらがな／カタカナ、全角／半角、型番6桁、複数キーワード検索
- PSAグレード・レアリティ・取引元の絞り込み
- 成約日・価格で並べ替え、最近の取引を表示
- 該当履歴をCSV出力。CSV／JSONの読み込みはその画面だけの置換です
- 検索条件をURLに保持、スマートフォン対応

## ファイル

- `dist/`：公開するサイト
- `dist/data.json`：共有する成約データ
- `dist/sync-status.json`：定期取得の状態
- `dist/sync-config.mjs`：GitHubの公開データURL・更新予定の表示
- `scripts/targets.json`：対象URL、日本語名、型番、PSAグレード
- `scripts/parse-alt.mjs`：公開表示の成約行を解析するヘルパー
- `scripts/core.test.mjs`：検索・CSV・グレード分離・異常値の検証

## 検証

Node.js 22以降で `npm test`。追加依存なし。9件の検証が成功しています。WebMCPは対応ブラウザで検索条件を変更できるよう登録していますが、この環境でのWebMCP実行検証は行っていません。

GitHub Pagesではこのフォルダの `index.html` から開けます。Sites版・GitHub Pages版とも公開JSONを直接読むため、データ更新時のサイト再構築は不要です。共有JSONを取得できないときは直前または同梱の履歴を表示し、最新データを確認できない旨を明示します。
